# elemental-guardians-game

A tiny browser game is live in `index.html`.

How to play:
- Open `index.html` in a browser, or serve the folder with a local static server.
- Move with WASD / Arrow keys.
- Fire with Space or mouse click.
- Switch elements with 1 / 2 / 3.
- Survive as long as you can and chase your best score.

This keeps the project playable without any build step or dependencies.
